# TestSprite — Installation Spotbook

1. Créer un compte sur [TestSprite](https://testsprite.com).
2. Générer une API key dans le dashboard TestSprite.
3. Ouvrir Cursor > Settings > Extensions > TestSprite.
4. Coller l'API key.
5. Dans Cursor Agent, exécuter:

```text
Initialise TestSprite sur le projet Spotbook
```

6. Vérifier que TestSprite lit bien `CLAUDE.md` et le code du projet.
