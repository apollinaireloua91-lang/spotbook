## Couleurs observées dans les maquettes

| Rôle | Hex | Utilisation |
|---|---|---|
| Fond principal | `#0A0E14` | Background global (très foncé, presque noir) |
| Surface/cartes | `#111820` | Cartes, champs input, bottom sheets |
| Bordures | `#1E2A38` | Contours de cartes et séparateurs |
| Accent principal | `#00D4FF` / `#00BFFF` | Boutons CTA, liens, accents (cyan/bleu vif) |
| Accent secondaire | `#7B61FF` | Badges, catégories (violet doux) |
| Texte principal | `#FFFFFF` | Titres et texte principal |
| Texte secondaire | `#8A9AAF` | Sous-titres, labels, placeholders |
| Succès/vert | `#00C851` | Badges "Selling Fast", statuts positifs |
| Orange | `#FF8C00` | Badges VIP, catégories événements |

**Note importante** : Les maquettes Stitch utilisent un accent **cyan/bleu (#00D4FF)** et du **violet (#7B61FF)** qui diffèrent de la charte AppColors noir et blanc strict définie dans CLAUDE.md. Les boutons CTA sont **cyan** dans les maquettes au lieu de **blanc** dans la charte.

## Patterns UI récurrents

- **Feed vidéo** : Plein écran TikTok-style, overlays semi-transparents, boutons latéraux (like, comment, share, book)
- **Bottom nav** : 4 onglets client (Home, Search, Bookings, Profile) / 6 onglets pro (Dashboard, Recherche, Caméra, RDV, Événements, Profil Pro)
- **Cartes** : Coins arrondis ~16px, fond surface sombre, bordure subtile
- **Boutons CTA** : Full-width, radius arrondi ~25px, fond cyan avec flèche →
- **Booking flow** : Bottom sheet multi-étapes (6 étapes avec barre de progression)
- **Inputs** : Fond surface sombre, icône à gauche, bordure subtile, radius 12px
- **Labels catégories** : Uppercase, lettre-spacing élevé, petite taille
- **Profil client** : Cover gradient bleu→violet, avatar circulaire, socials connectés, 3 onglets (Favorites, History, Tickets)
- **Profil pro** : Style terminal/monospace, sections STRATEGIC OVERVIEW, REACH ANALYTICS, VISUAL STREAMS
- **Événements** : Cover plein écran, overlay gradient, ticket types en chips sélectionnables

## Style général

- **Dark mode exclusif** — fond très sombre (#0A0E14), jamais de fond blanc
- **Style premium/tech** — entre TikTok (feed vidéo) et Linear (dashboard pro)
- **Accent cyan** pour tous les CTA et éléments interactifs
- **Typographie bold** pour les titres, monospace sur le profil pro
- **Micro-interactions** : checkmarks animés, progress bars, shimmer loading
- **Touch targets larges** : boutons minimum 48px
- **Padding horizontal** : ~20px constant
